# Scripts : film, court-métrage, vidéo, podcast, théâtre, publicité

Lis aussi `critique.md`. Les conventions de format varient : **demande le format attendu** (producteur, plateforme, concours) quand il y en a un.

## Avant d'écrire

1. **Logline** (une phrase) : qui, veut quoi, contre quoi, avec quel enjeu.
2. **Durée et support** : une page de scénario au format standard représente environ une minute à l'écran ; une vidéo en ligne se pense en secondes de rétention ; un podcast en minutes de parole.
3. **Public et ton.**
4. **Contraintes de production** : lieux, budget, nombre de personnages, voix off.

## Structure

- **Court-métrage (5-20 minutes) :** une situation, un changement, une chute. Évite d'y mettre un long métrage entier.
- **Long métrage :** trois actes ou équivalent. Définis : incident déclencheur, point de bascule du milieu, point bas, climax, résolution. Fiche par séquence : objectif, conflit, changement.
- **Série :** épisode autonome + arc de saison ; bible (personnages, ton, règles du monde).
- **Vidéo en ligne :** **accroche** dans les premières secondes (promesse ou question forte), développement par segments courts, relance régulière, appel à l'action simple. Ne promets pas ce que la vidéo ne livre pas.
- **Podcast / audio :** tout passe par la voix et le son : indique les ambiances, silences, transitions ; phrases courtes à dire à voix haute.
- **Théâtre :** action par la parole et le conflit ; didascalies sobres ; contraintes de scène réelles.
- **Publicité / spot :** un message, une émotion, une marque ; durée exacte ; le produit apparaît tôt et clairement.

## Format

**Scénario (convention courante) :**
```
INT. CUISINE - NUIT

Description courte, au présent, de ce qu'on voit et entend.

AMINATA
(sans lever les yeux)
Tu rentres tard.

MOUSSA
Le car est tombé en panne.
```
- Titre de scène (INT./EXT., lieu, moment) ; action au présent ; nom du personnage ; dialogue.
- On n'écrit que **ce que l'on peut voir ou entendre**. Pas de pensées non filmables.
- Pour un **format de diffusion précis** (Fountain, texte brut, tableau deux colonnes pour vidéo : « Image | Son »), suis ce qui est demandé.

**Script vidéo / podcast à deux colonnes :**
```
IMAGE / ACTION | SON / VOIX OFF
Plan large du marché | « Chaque matin, ... »
```

## Écrire les dialogues

- Chaque personnage a une manière de parler distincte (longueur, vocabulaire, hésitations).
- Le dialogue cache quelque chose : on parle de A pour dire B.
- Coupe les politesses et les redites ; démarre tard, sors tôt.
- Lis à voix haute (en pensée) : si une phrase ne se dit pas, réécris-la.
- Respecte les langues réelles des personnages (français, wolof, anglais…) ; si tu n'es pas sûr d'une expression dans une langue, **signale-le** plutôt que d'inventer.

## Critique spécifique

Pose : Le premier plan accroche-t-il ? Chaque scène change-t-elle quelque chose ? Le héros veut-il quelque chose de concret ? Des scènes à supprimer ? La fin est-elle méritée ? Le dialogue sonne-t-il vrai ? Le script est-il **tournable** avec les contraintes données ?

## Pièges
- Scènes d'exposition où l'on s'explique des choses connues.
- Personnages passifs.
- Dialogues trop propres, trop explicatifs.
- Format : plus de pages que la durée visée.
- Copier des scènes ou des répliques de films existants : interdit.
