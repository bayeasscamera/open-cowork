# Registres de continuité

Pour tout texte long (livre, série, script long, dossier de plusieurs parties). **Lis les registres avant chaque partie, mets-les à jour après.** Crée-les dans `ecriture/<projet>/registres/`.

## Règle d'or
Un registre n'a de valeur que s'il est **à jour** et **précis**. Une ligne par fait, datée par la partie où il apparaît (`ch03`).

## Registres de base

### `personnages.md` (fiction, mémoires, études de cas)
```
## <Nom>
Rôle : 
Âge / apparence / signes distinctifs (ne les change pas sans raison) :
Voix (façon de parler, tics, vocabulaire) :
Désir / peur / secret :
Relations (avec qui, état actuel) :
Évolution (par partie) : ch01 ... / ch04 ...
```

### `chronologie.md`
Événements dans l'ordre réel de l'histoire ou des faits, avec date ou repère. Signale les écarts entre l'ordre du récit et l'ordre réel.

### `glossaire.md`
Termes inventés ou techniques, noms de lieux, orthographe retenue, définition en une ligne, première occurrence.

### `intrigues-et-promesses.md`
Questions posées au lecteur et non résolues, éléments introduits qui doivent servir plus tard (le fusil de Tchekhov), promesses faites dans l'introduction. Coche quand c'est résolu.

### `decisions.md`
Choix irréversibles ou structurants : point de vue, temps de narration, ton, ce qu'on a écarté et pourquoi, validations de l'utilisateur.

### `guide-de-style.md`
10 lignes : longueur des phrases, registre, mots favoris et mots interdits, ponctuation, dialogues, humour, temps du récit, règles typographiques choisies.

## Registres pour le documentaire

### `sources.md`
```
[S1] Référence complète (auteur, titre, date, lien)
Statut : vérifiée / à vérifier
Ce qu'elle établit : (une ligne)
Utilisée dans : ch02, ch05
```
**Règle :** aucune citation ni référence dans le texte sans entrée vérifiée ici. Sinon « [à vérifier] ».

### `faits-verifies.md`
Chiffres, dates, définitions, avec la source `[S#]` et la date de vérification.

## Résumés et état

### `resumes.md`
Après chaque partie : 5 lignes (ce qui se passe, ce qui change, ce qui est introduit, où l'on s'arrête). C'est ce résumé, pas le texte entier, qui alimente la partie suivante.

### `../etat.md`
```
Étape : 
Dernière partie terminée : 
En cours : 
Décisions récentes : 
Prochaines actions : 
Budget / volume utilisé : 
```

## Contrôle de cohérence (avant et après chaque partie)
- Les noms, âges, lieux et chiffres correspondent-ils aux registres ?
- Une information n'est-elle pas révélée deux fois ou contredite ?
- Les promesses ouvertes avancent-elles ?
- Le style respecte-t-il le guide ?
Signale chaque contradiction trouvée et corrige-la dans le texte ou dans le registre, selon ce qui est vrai.
