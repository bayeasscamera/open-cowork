# Critique et révision

## Pourquoi une grille
Un modèle qui relit son propre texte le trouve presque toujours bon. La grille force un jugement chiffré, appuyé sur des **passages cités**.

## Méthode

1. **Relis comme un lecteur exigeant**, pas comme l'auteur. Si un sous-agent éditeur est disponible, confie-lui le texte et la grille **sans ton raisonnement**.
2. **Note chaque critère de 1 à 5.** Pour tout critère ≤ 3, **cite le passage faible** et dis pourquoi.
3. **Classe les corrections** : bloquant (sens, faits, structure), important (rythme, clarté), cosmétique.
4. **Corrige** d'abord les bloquants. **Deux passes maximum** : au-delà, on lisse la voix et on abîme le texte.
5. **Reconsidère** les notes après correction ; dis honnêtement ce qui reste faible.
6. **Ne touche pas** à ce qui fonctionne (note ≥ 4).

Seuil : un critère sous 3 oblige à corriger ; une moyenne sous 3,5 sur un texte important demande une seconde passe.

## Grille universelle (tous textes)
| Critère | Question |
|---|---|
| Objectif | Le texte obtient-il ce qu'il vise ? |
| Lecteur | Adapté à son niveau, son état d'esprit, son temps ? |
| Clarté | Compris du premier coup ? |
| Structure | Ordre logique, transitions, début et fin ? |
| Précision | Concret, exact, sans généralités ni inventions ? |
| Voix | Cohérente, naturelle, fidèle à l'utilisateur ? |
| Rythme | Phrases variées, pas de mécanique ? |
| Économie | Rien à couper sans perte ? |
| Fiabilité | Faits, chiffres, sources vérifiés ou signalés « [à vérifier] » ? |

## Grilles par genre (à ajouter à l'universelle)

**Fiction :** désir et enjeu du personnage ; conflit dans chaque scène ; dialogues distincts ; montrer plutôt qu'expliquer ; rythme du récit ; cohérence (registres) ; fin méritée.

**Non-fiction :** promesse tenue ; thèse claire ; exemples concrets ; preuves vérifiées ; chaque chapitre répond à une question ; actionnable.

**Script :** accroche ; chaque scène change quelque chose ; dialogue parlable ; tournable avec les contraintes ; durée respectée.

**Administratif :** demande impossible à manquer ; objet précis ; champs complets ; ton adapté au destinataire ; conformité aux usages donnés ; aucune information inventée.

**Poésie :** image neuve ; idée centrale ; sons et rythme ; forme respectée ; chute ; absence de clichés.

**Brainstorming :** variété ; originalité ; réalisme ; actions concrètes proposées.

## Relecture globale d'un texte long
Une question par passe : structure, cohérence (registres), rythme, promesses tenues, répétitions, début et fin. Signale les déplacements ou coupes proposés **avant** de les appliquer, et sauvegarde les versions.

## Format du rapport de critique
```
Notes : Objectif 4 | Lecteur 3 | Clarté 4 | ...
Points forts (2 à 3) :
Problèmes (ordre de gravité), chacun avec le passage cité :
Corrections appliquées :
Ce qui reste faible :
```
Montre ce rapport à l'utilisateur pour un pilote ou un texte important ; pour un texte court, applique les corrections sans l'encombrer.
