# Autres formats d'écriture

Méthode commune : **objectif → lecteur → message principal → structure → premier jet → critique courte → version finale**. Voici la structure et les pièges de chaque format. Pour tout autre format non listé, applique la méthode commune et demande un exemple de ce qui est attendu.

## Discours / allocution / hommage
- Écrit pour l'**oreille** : phrases courtes, répétitions utiles, rythme, pas de longues incises.
- Structure : ouverture qui capte, message central (une idée), 2 ou 3 appuis (histoires, exemples), conclusion qui appelle à agir ou émeut.
- Durée : environ 120 à 150 mots par minute à voix haute.
- Hommage : détails précis fournis par l'utilisateur, jamais inventés.

## Article / blog / tribune
- Titre honnête qui promet ce que l'article donne ; chapô de 2 phrases ; une idée par paragraphe ; exemples concrets ; conclusion qui tranche.
- Faits sourcés ; opinions assumées comme telles.

## Newsletter / mail marketing
- Objet court et clair ; première phrase utile ; un seul appel à l'action ; ton constant ; pas de promesses fausses.

## Communiqué de presse
- Titre factuel, chapô (qui, quoi, quand, où, pourquoi), détails, citation (fournie), contact. Pyramide inversée.

## Mail professionnel
- Objet précis ; demande ou information en première phrase ; contexte minimal ; prochaine étape et échéance ; une page maximum.

## Présentation orale / support de diapositives
- Un message par diapositive, très peu de texte, une histoire en fil rouge. Le fichier de présentation lui-même : voir le skill `pptx`.

## Post pour réseaux sociaux
- Accroche dans la première ligne, valeur concrète, ton de la plateforme, appel à l'échange. Pas de faux témoignages.

## CV / lettre de motivation / profil
- **N'invente aucune expérience, diplôme, date ni compétence.** Mets en valeur ce qui est réel : résultats chiffrés fournis, responsabilités, outils.
- Lettre : pourquoi cette organisation, pourquoi moi (preuves), ce que j'apporte, disponibilité. Une page.

## Fiche produit / description
- Bénéfice d'abord, caractéristiques ensuite, informations pratiques, ton de la marque. Pas d'affirmation non vérifiable (« le meilleur », données techniques inventées).

## FAQ / mode d'emploi / procédure
- Questions telles que les posent les gens ; réponse courte d'abord, détail ensuite ; étapes numérotées avec un verbe d'action ; résultat attendu à chaque étape.

## Légende, slogan, accroche
- Génère plusieurs variantes (voir `brainstorming.md`), puis choisis avec critères.

## Traduction et adaptation
- Garde le sens et le ton, adapte les références culturelles ; signale les expressions ambiguës ; ne traduis pas mot à mot.
